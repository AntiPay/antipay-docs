# AntiPay Docs

Official documentation for AntiPay.

AntiPay is a payment verification platform for merchants and developers.  
This repository contains integration guides, API references, webhook docs, error codes, and examples.

## Base URL
https://pay.antipay.site/v1/

## Available Guides
- API Reference
- Authentication
- Payment Session Creation
- Payment Verification
- Webhook Integration
- Error Codes
- FAQ

## Important
- Never expose your API key in client-side code.
- Use backend-to-backend requests for verification.
- Webhook should be treated as the source of truth for merchant-side automation.
